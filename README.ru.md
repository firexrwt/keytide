# Keytide

Бесплатный локальный переключатель раскладки RU/EN и корректор опечаток для macOS 13+. [English](README.md).

Набираете `ghbdtn ` - получаете `привет `, набираете `руддщ ` - получаете `hello `: после пробела Keytide исправляет слово, переключает системную раскладку для дальнейшего ввода, а одиночный Option отменяет исправление. Нативное приложение в строке меню, без телеметрии и платных зависимостей; в сеть ходит только проверка обновлений.

## Возможности

- Слова в неверной раскладке исправляются после пробела в обе стороны, от двух букв (`lf` -> `да`). Регистр сохраняется. Английские сокращения, набранные в русской раскладке, тоже исправляются (`дуеэы` -> `let's`).
- Очевидные опечатки исправляются от трёх букв и только если исправление отличается на одну правку.
- Одиночный Option отменяет последнее исправление и возвращает прежнюю раскладку. Control+D защищает слово от исправлений. Оба сочетания настраиваются.
- Защищённые слова работают и как цель раскладки: защищено `локи` - `kjrb` станет `локи`.
- Обучение по желанию: после двух отмен одного слова оно больше не исправляется. Выученные слова видны в настройках, их можно забыть.
- Исключения приложений (по умолчанию терминалы и редакторы кода), пауза, автозапуск, экспорт и импорт профиля.
- Обновляется сам в один клик из меню и сохраняет разрешение «Универсальный доступ» (начиная с 0.1.1). «Проверить обновления» отвечает окном: версия актуальна (с версией на GitHub) или вышла новая, с кнопкой «Обновить». После обновления настройки один раз простыми словами показывают, что изменилось (и пункт «Что нового» в меню).
- Интерфейс на русском и английском, по языку macOS (для Keytide можно выбрать другой в Системных настройках > Основные > Язык и регион > Приложения).
- Вкладка «О приложении» (и пункт «О Keytide» в меню): версия, ссылки, переключатель диагностики, «Сохранить отчёт» и «Сообщить об ошибке» - открывает форму на GitHub с уже заполненными версией и macOS.
- Встроенный словарь RU/EN: около 1,5 млн словоформ в индексе на 1,4 МБ, остальное проверяет системный корректор macOS.

## Как это работает

Keytide нужно разрешение macOS «Универсальный доступ», чтобы видеть нажатия и править текст.

- В TextEdit, Safari, Chrome, Helium и Codex он читает поле, сверяет слово и курсор и заменяет слово проверяемой транзакцией.
- В остальных приложениях он помнит только набираемое слово (до 64 символов, сбрасывается на каждом пробеле) и после пробела стирает его Backspace'ами и набирает исправленное. Enter исправление не запускает: сообщение уходит как набрано.
- Если такое поле всё же читается (Raycast, большинство нативных приложений, приложения на Electron вроде Claude desktop), на пробеле Keytide читает слово перед курсором. Поэтому слово исправляется целиком, где бы оно ни стояло, даже если вы дописываете уже существующее, а обрывки никогда не попадают в выученные. В приложениях на Electron Keytide включает их дерево доступности (`AXManualAccessibility`) при первой нажатой там клавише, никогда в менеджерах паролей, и выключает при выходе из Keytide или добавлении приложения в исключения; это стоит такому приложению около 20 МБ. Где поле не читается совсем, набранное слово всё равно исправляется, но отмена слова, начатого после клика, стрелки или Backspace за начало слова, ничему Keytide не учит: это может быть часть более длинного слова.
- Ничего не исправляется при защищённом вводе, в полях паролей, в исключённых приложениях, когда фокус не на текстовом поле, при выделенном тексте и если после пробела что-то нажато.

История текста, буфер обмена и телеметрия не используются. Диагностика включается вручную («О приложении» > «Подробная диагностика», сама выключается через 30 минут) и записывает только пронумерованные шаги решений: без набранного текста, без длин слов (кроме исправленных), без названий приложений (они идут как app1, app2) и без времени. Она хранится в памяти и не пишется в системный журнал. «Сохранить отчёт» сначала показывает весь анонимный отчёт (версии, настройки, две рабочие раскладки, количества и эти шаги); никуда не отправляется, файл прикладываете вы сами.

В сеть Keytide ходит только за обновлениями: раз в сутки спрашивает у api.github.com последний релиз (отключается в настройках; «Проверить обновления» в меню работает всегда) и скачивает релиз с github.com (файл отдаёт хранилище GitHub на *.githubusercontent.com) только по нажатию «Обновить». Обновление ставится, только если и dmg, и приложение в нём подписаны тем же сертификатом, что и работающее приложение. Если Keytide отклонил обновление из-за подписи, не ставьте эту версию вручную.

## Установка

1. Скачайте dmg из [Releases](https://github.com/firexrwt/keytide/releases), откройте его и перетащите Keytide в «Программы».
2. Приложение не нотаризовано. Если macOS не даёт его открыть, зайдите в Системные настройки > Конфиденциальность и безопасность и нажмите «Всё равно открыть» (правый клик > «Открыть» для этого не работает начиная с macOS 15).
3. Разрешите Keytide в Системных настройках > Конфиденциальность и безопасность > Универсальный доступ.

Обновления из меню сохраняют разрешение. При переходе с 0.1.0 или после установки сборки с другим сертификатом macOS оставляет старую запись, которая больше не подходит: удалите Keytide там кнопкой `-`, добавьте приложение кнопкой `+` и включите. Просто переключить существующий тумблер недостаточно.

## Ограничения

- Версия экспериментальная. Каждое приложение требует живой проверки: тесты и сборка не доказывают работу глобального ввода.
- Если приложение само переписывает слово на том же пробеле (автоисправление, замена текста) в поле, которое Keytide не может прочитать, число Backspace может разойтись с текстом. Где поле читается, Keytide сначала сверяет текст и пропускает слово.
- Вне пяти приложений выше Enter исправление не запускает.

## Сборка из исходников

Xcode или Command Line Tools со Swift 5.9 или новее.

```sh
swift test                 # debug
swift test -c release      # конфигурация, которая поставляется
bash scripts/build-app.sh  # build/Keytide.app, hardened runtime, подпись (см. ниже)
bash scripts/install.sh    # release-тесты, сборка, замена /Applications/Keytide.app, запуск
bash scripts/make-dmg.sh   # build/Keytide-<версия>.dmg
```

Иконка генерируется: `swift scripts/make-icon.swift build/AppIcon.iconset && iconutil -c icns build/AppIcon.iconset -o Resources/AppIcon.icns`.

Окно dmg тоже генерируется. `swift scripts/make-dmg-background.swift build/dmg-bg && tiffutil -cathidpicheck build/dmg-bg/background.png build/dmg-bg/background@2x.png -out Resources/dmg/background.tiff` рисует фон; `bash scripts/make-dmg-layout.sh` один раз сохраняет раскладку окна из Finder в `Resources/dmg/DS_Store` (перезапускать только при смене геометрии). `make-dmg.sh` лишь копирует оба файла, поэтому CI не нужен Finder.

`build-app.sh` и `make-dmg.sh` подписывают сертификатом `Keytide Code Signing`, если в связке ключей есть его закрытый ключ, иначе ad-hoc: такая сборка теряет «Универсальный доступ» при каждой пересборке, не умеет обновляться сама и не годится как обновление.

Релизы собирает GitHub Actions: тег `v<версия>`, совпадающий с `CFBundleShortVersionString`, запускает release-тесты, подписывает приложение и dmg, сверяет обе подписи с закреплённым сертификатом и создаёт черновик релиза, текст которого - раздел этой версии из [CHANGELOG.md](CHANGELOG.md) (без него тесты падают). Задача идёт в окружении `release`: там лежат секреты `KEYTIDE_CERT_P12` и `KEYTIDE_CERT_PASSWORD`, и запуск ждёт подтверждения владельца.

## Сертификат подписи

Официальные сборки подписаны самоподписанным сертификатом `Keytide Code Signing`, отпечаток SHA-256:

```
1D:FC:6B:08:D3:DB:A2:84:2A:6A:BE:E8:A7:D1:D5:91:F1:16:53:82:78:BC:C4:B4:0C:9A:5D:C6:B8:E4:98:90
```

Проверить скачанное: `codesign -dvv Keytide.app` (строка Authority) и `codesign -d -r- Keytide.app` (в требовании указан SHA-1 сертификата, `f17aa23f772d72310797b7e3aabd4db522de9923`; сертификат действует до 2046 года). Закрытый ключ есть только в окружении `release` и в офлайн-копии. Самоподписанный сертификат нельзя отозвать: если ключ когда-нибудь потеряется или утечёт, об этом скажут этот README и заметки к релизу, а новый сертификат потребует одной ручной переустановки и нового разрешения «Универсальный доступ».
